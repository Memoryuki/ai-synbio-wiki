一个支架，三个功能模块

PR3H 采用通过环区连接的内外螺旋支架。研究以 Crick 参数化生成候选骨架，以 GeneralizedKIC 连接螺旋，再用 HBNet 搜索界面氢键网络，其余片段由 RosettaDesign 设计。结构模型为变体实验提供设计假设。[图1a–d]

PR3H 的功能分区
模块 设计逻辑 验证入口
His–Asn 网络 中性条件下稳定界面，酸化时改变相互作用 网络层数对照、SEC、膜泄漏
正电荷环区 通过静电作用与 siRNA 结合 凝胶阻滞、颗粒表征、流式摄取
末端疏水片段 调节膜相互作用 疏水性变体、膜泄漏、细胞活力

用网络层数检验酸响应假设

PR3H、PR2H 和 PR1H 分别包含三层、两层和一层 His–Asn 网络。减少网络层数时，将指定的 His–Asn 对替换为疏水 Val–Leu 对，保持其余支架作为比较基础。[SI Table S1]研究通过预测结构与 CD 判断整体螺旋特征，再用 SEC 和脂质体泄漏比较酸响应行为。

在测试条件下，PR3H 在 pH 5.5 出现明显晚洗脱组分，在 pH 5.0 下不再出现原寡聚峰；PR2H 与 PR1H 的类似变化需要更酸性条件。这一比较支持通过网络层数调节酸响应区间。[图1g；补充图 S2–S4]

膜活性与相容性的取舍

末端疏水性变体 PR3HM1 增强膜扰动，却伴随更差的细胞相容性；PR3HM2 打断疏水连续性后，膜泄漏减弱。环区电荷同样存在取舍：较低电荷不利于复合与摄取，较高电荷在高 N/P 条件下增加细胞毒性。PR3H 因而被选为后续表面工程的先导支架。[图3–4]

表面工程：屏蔽与相互作用的平衡

研究进一步在 C 端引入用于 PEG 偶联的半胱氨酸，并比较 PEG 分子量与共轭比例；在 N 端引入富含精氨酸或 Asp/Glu 的带电片段。PEG 设计旨在改变表面屏蔽，电荷工程则检验器官功能读出的差异。

PEG 与 N 端电荷共同调节载体的表面性质，通过颗粒表征和器官 mRNA 读出评价其影响。[图5；SI S11–S13]
